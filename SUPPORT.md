# Support

coilEM 0.2.0 is a source-built developer preview without a support SLA.

Use [GitHub Issues](https://github.com/coilemdev/coilem/issues) for:

- reproducible installation or build failures;
- crashes and incorrect or corrupt saved-run behavior;
- unexpected solver errors on an accepted configuration;
- documentation problems; and
- focused feature requests.

Include the coilEM version and commit, operating system and architecture,
Python/Node/Rust/Gmsh versions, exact command or UI path, sanitized input when
possible, expected result, actual result, and relevant logs. Do not attach
private designs unless you are comfortable making them public.

Use [GitHub Discussions](https://github.com/coilemdev/coilem/discussions) for
usage questions, ideas, and sharing what you built.

GitHub Issues and Discussions are public. Suspected vulnerabilities must instead use the private
route in [SECURITY.md](SECURITY.md). There is no guaranteed first-response or
fix deadline.
