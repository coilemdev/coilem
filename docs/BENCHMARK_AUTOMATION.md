# Release benchmarks

Release benchmark collection and evidence retention take place in the private coilEM experiments repository. Use its publication policy and record the exact release source commit. Public benchmark publication is paused across repository updates, workflow artifacts, release assets, Pages and packages.

The last public Windows and macOS records measured `5e6fab283d165dc9e2ccec7e1a477c7080a993c4` under A-F protocol 1.10.0. They remain available for local replay with `coilem benchmark`. The numerical gates, dependency checks and source hashes still apply. Changed physics have no matching public qualification.

See the [A-F protocol](../benchmarks/af-v1.10/README.md) and [platform records](../benchmarks/records/README.md).
